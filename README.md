# 研修音声レコーダー

ブラウザで再生している音を録音して音声ファイルにする単一HTMLアプリ。**録音は端末内で完結し、どこにも送信されません。**

購入して視聴できる研修動画を、本人が移動中に復習するために音声で残す用途で作りました。

## 使う

- 公開ページ: https://chikashimasaki-lgtm.github.io/audio-recorder/
- **https のページから使ってください。** `file://` で開くとタブ音声の取得がブラウザに拒否される場合があります

### 手順

1. 「録音を開始」を押す
2. 共有するタブとして **研修を再生するタブ** を選び、**「タブの音声も共有する」にチェック**
3. 研修の再生を始める
4. 終わったら「停止して保存」

録音中はこのタブを閉じないでください。長い研修では途中で「ここまでを保存」しておくと、万一のときに全部を失わずに済みます。

### できること

- 経過時間・入力レベル・推定ファイルサイズの表示
- 一時停止／再開、途中保存、最大録音時間での自動停止
- **無音の検知** … 15秒間まったく音が入らなければ警告します（「タブの音声も共有する」のチェック忘れが一番多い原因）
- **しおり** … 気になった箇所でボタンを押すと `00:12:34　メモ` の形で記録され、音声と一緒に `_しおり.txt` として保存されます
- 画面のスリープ抑止（Wake Lock）。長時間の録音中に端末が寝て止まるのを防ぎます
- 音質は 32〜128 kbps から選択（既定64 kbps。3時間で約82MB）。モノラルを要求するので、同じビットレートでも音質が保たれます
- 保存形式は環境に合わせて選択（Chrome: `.webm`（Opus）／Safari: `.m4a`（AAC）。**同じビットレートなら Opus の方が低音質側に強い**）
- **Gemini に読ませる WAV も同時に保存**（既定ON）。Gemini API が受け付けるのは wav/mp3/aiff/aac/ogg/flac だけで、**Chrome の録音形式（WebM）は読めない**ため、16kHz・モノラルの WAV へ変換して並べて保存します

## この道具がしないこと

- **マイクを使いません。** `getUserMedia` はどこからも呼んでいないため、周囲の話し声や生活音は入りません。録音されるのは共有したタブが鳴らす音だけです
  - ただし共有の種類で「画面全体」「ウィンドウ」を選ぶと、そのパソコンが鳴らす他の音（通知音など）は混ざります。その場合は画面に注意が出ます
- **配信されているファイルを直接取りに行きません。** ストリームURLの解析やダウンロード機能はありません
- **技術的保護手段を回避しません。** 保護された配信の音声はブラウザの仕様上こちらへ無音として届きます。その場合は無音警告が出るので「録れていない」ことが分かります
- ログイン情報を扱いません

録音したものは本人の私的利用の範囲で使い、配布・共有しないでください。

## 開発

```
npm install     # 依存なし（スクリプトのみ）
npm run build   # src/ から index.html を組み立て直す
npm test        # 純ロジックと配線の検査（131項目）
```

| パス | 役割 |
| --- | --- |
| `src/lib.js` | 純ロジック（ファイル名・時刻表記・形式選択・無音判定・共有種別の注意）。ブラウザとテストで共用 |
| `src/app.js` | 画面と `getDisplayMedia` / `MediaRecorder` の配線 |
| `src/index.html` | 雛形。`build_html.js` がここへスクリプトを流し込む |
| `index.html` | 配布物（生成物・約29KB）。直接編集せず `npm run build` する |

### テストについて

録音そのもの（`getDisplayMedia` の許可ダイアログ、`MediaRecorder`）は利用者の操作が要るため自動化できません。`npm test` で固定しているのは、その周りで静かに間違えやすいところです。

- 時刻・サイズの表記、ファイル名の組み立て、録音形式の選択、無音判定の境界
- **配線の静的検査** … `app.js` が触る要素IDが全てHTMLに存在すること、`index.html` が最新のソースから生成されていること（`src/` を直して `npm run build` を忘れる事故を防ぐ）
- **WAVの検証** … 自作したWAVを python3 の `wave` モジュールで開き、チャンネル数・ビット深度・サンプル数・波形（440Hzのゼロ交差数）まで確認しています

ブラウザでの通し確認は、この開発環境（aarch64）で動くヘッドレスChromeが無いため実施できていません。下記は手で確認してください。

- [ ] 録音中にマイクの使用許可を求められない・アドレスバーにマイクのアイコンが出ない
- [ ] 「画面全体」を選んで録音 → 他の音が混ざる旨の注意が出る（録音は続く）
- [ ] 適当なタブで音声を共有して録音 → 保存したファイルが再生できる
- [ ] 「タブの音声も共有する」のチェックを外して共有 → 15秒で無音警告が出る
- [ ] 一時停止・再開・途中保存・しおり
- [ ] 保存時に `.webm` と `.wav` が並んで保存され、WAVが Gemini（AI Studio 等）で読める
- [ ] 共有を停止、または対象タブを閉じる → 自動で停止して保存される
